# Power BI / Metabase 看板说明

## 页面 1：经营概览

- KPI：订单量、GMV、活跃购买用户、客单价、平均配送天数、延迟配送率。
- 图表：月度订单量与 GMV 趋势；支付方式 GMV；州级订单地图。
- 筛选器：订单月、客户州、支付方式。

## 页面 2：用户复购与 Cohort

- KPI：复购用户数、复购率、首月留存率。
- 图表：首购 cohort 热力图；每个 cohort 的活跃用户曲线。
- 结论模板：描述哪个 cohort 留存更高，再排查获客渠道、品类或配送体验差异；没有因果证据时不要写成原因。

## 页面 3：品类与订单价值

- 图表：Top 10 品类 GMV、订单量与平均单品价格；品类-订单价值散点图。
- 说明：`allocated_gmv` 将订单实付金额按订单内商品件数均分，仅用于品类层面的近似比较。

## 页面 4：配送体验

- 图表：州级平均配送天数与延迟配送率；配送时长分布。
- 行动框架：先识别高订单量且延迟率较高的地区，再提出待验证的履约优化假设。

## 面试展示顺序

1. 先讲公开匿名化数据与业务问题。
2. 展示数据粒度、指标定义和去重原则。
3. 从月度趋势进入用户复购、品类和配送体验。
4. 给出三条数据支持的假设，并说明仍需 A/B 测试或业务数据验证。
