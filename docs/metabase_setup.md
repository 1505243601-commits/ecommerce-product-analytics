# Metabase 看板搭建指南

## 当前准备情况

本项目已经生成 SQLite 数据库：`data/analytics/ecommerce.db`，以及 6 张可复制的原生 SQL 问题卡：`sql/metabase_questions.sql`。

本机未检测到 Docker，因此暂未启动本地 Metabase 服务。不要把 SQL 查询结果截图当作看板交付；需要在 Metabase 中保存问题卡并组成仪表板。

## 接入步骤

1. 启动一个你可访问的 Metabase 实例（个人本地实例或团队已提供的实例均可）。
2. 新建数据库连接，选择 SQLite，并指向 `data/analytics/ecommerce.db`。
3. 依次复制 `sql/metabase_questions.sql` 的六段查询，保存为对应问题卡。
4. 新建仪表板“电商用户行为、复购与配送体验分析”，按以下四页或四个分区编排。

## 页面布局

### 经营概览

- Card 1：KPI 数字卡。
- Card 2：双轴或两个折线图，分别展示 GMV、订单量与客单价趋势。

### 用户复购

- Card 3：一次购买与复购用户占比。
- Card 4：按首购月和 cohort_index 配置热力图，颜色使用 retention_rate_pct。

### 品类表现

- Card 5：按 allocated_gmv 排序的条形图。
- 口径备注：allocated_gmv 是按订单内商品件数均分的实付金额，仅适合近似横向比较。

### 配送体验

- Card 6：州级延迟配送率与平均配送时长，可用散点图或排序表。
- 添加订单月、客户州和支付方式筛选器；筛选器应仅链接到含相应字段的问题卡。

## 交付检查

- 每张图显示清晰的中文标题、指标单位和时间范围。
- 看板中明确标注数据为公开匿名化历史数据。
- 结论写为数据支持的“待验证假设”，不要声称已产生收入或履约改善。
- 导出 3 至 5 张关键截图并写入 README；保留数据库、SQL 与口径文档，确保面试时可复现。
