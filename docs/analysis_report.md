# 第一版分析报告

> 数据：公开匿名化 Olist 历史订单数据。所有结论描述数据中的相关性，不代表因果关系，也不代表任何真实业务方的当前经营表现。

## 数据与口径

- 时间范围：2016-09-15 至 2018-08-29。
- 分析对象：`delivered` 状态订单；共 96,478 笔订单、93,358 位唯一用户。
- GMV：订单支付金额之和，合计 15,422,461.77；平均客单价为 159.86。
- 数据质量：1 笔已送达订单缺失支付记录。它保留在订单量分析中，GMV 汇总不会计入该笔缺失金额。

## 已核验发现

1. **复购空间较大**：有 2,801 位用户至少完成两笔订单，在 93,358 位用户中占 3.00%。后续应以首购月份、品类和履约体验切分复购人群，而不是直接断言某因素导致低复购。
2. **销售高峰集中在 2017-11**：该月完成 7,289 笔订单，GMV 为 1,153,528.05。需要结合促销日历与流量来源进一步解释峰值。
3. **GMV 主要来自信用卡支付**：信用卡支付覆盖 74,303 笔订单，GMV 为 12,286,509.84；该结果适合作为支付方式分层的起点，不等同于支付方式提升了转化。
4. **头部品类集中**：`beleza_saude`、`relogios_presentes`、`cama_mesa_banho` 位列按分摊 GMV 计算的前三品类。分摊 GMV 将订单实付金额按商品件数均分，仅用于近似横向比较。
5. **配送体验存在地区差异**：订单数不少于 100 的州中，AL、MA、PI 的延迟配送率分别为 23.93%、19.67%、15.97%。这些地区应优先进入履约时长、商家和物流路径的后续排查清单。

## 下一步验证

- 在 Metabase 中用 `monthly_kpi`、`cohort_retention`、`category_kpi` 和 `fact_orders` 建立 4 个问题页。
- 为高延迟州增加订单量和配送时长分布，避免只按比例判断优先级。
- 对首购 cohort 比较首单品类、客单价、支付方式和配送体验；结论只写为待验证的复购假设。
- 如要提出履约或营销动作，定义主指标、护栏指标、分流规则和观察周期，再称为实验方案。
