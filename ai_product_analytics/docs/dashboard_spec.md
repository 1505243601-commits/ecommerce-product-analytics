# 运营看板设计

## 页面一：核心漏斗

- 日期筛选器：`event_date`
- 关键卡片：访问用户、提交用户、生成成功用户、结果采纳用户
- 趋势图：每日提交率、生成成功率、结果采纳率
- 下钻维度：`platform`、`model_version`

## 页面二：功能使用与异常排查

- 功能使用排行：按 `feature` 统计去重用户和事件数
- 模型版本对比：按 `model_version` 统计生成成功与采纳表现
- 数据质量表：缺失属性数、重复记录数、异常事件数

## 周度复盘流程

1. 观察漏斗各环节是否存在环比异常；
2. 按端、功能、模型版本下钻定位变化来源；
3. 联合产品确认近期功能、模型或埋点版本变更；
4. 记录结论、待验证假设与后续动作，不将相关性直接表述为因果结论。
